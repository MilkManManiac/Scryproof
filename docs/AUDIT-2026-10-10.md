# Scryproof audit, 2026-10-10

Wes: "lets do a great audit on this system. see what we can improve in all aspects."

Six read-only reviews (server, infra/ops, web client, desktop, activities, tests/docs/process) plus a dependency and repo check. Nothing was changed. Every finding below was read in the code; the ones marked PLAUSIBLE were reasoned but not run. Severity is about what it costs Wes and his friends, not textbook CVSS.

Facts measured: `npm audit` 0 vulnerabilities (root and desktop); `.npmrc` has ignore-scripts, save-exact, min-release-age 7; typecheck clean; server 384, web 561, desktop 88 pass (47 Mac tests skip on Windows); no CI; git pack 437 MB, of which 265 MB is 70 copies of `web/public/desktop-update/client.bin`; web main chunk 1.7 MB JS.

## Do these first (data loss or privacy)

1. **HIGH, CONFIRMED. Pass-along vocals live on the unencrypted root disk.** `pass-along-store.service:11-12` uses `StateDirectory` at `/var/lib/pass-along-store`, not the vault. Members' recorded voices are readable from a DigitalOcean snapshot. Breaks non-negotiable 9. Fix: adopt the directory into the vault (`20-vault-adopt.sh`) and gate the unit like the main app.
2. **HIGH, CONFIRMED. Three services start at boot without the vault:** activities nginx (`infra/activities/provision.sh:40`), pass-along store (`publish-pass-along.sh:79`), hero-line relay. `RequiresMountsFor=/srv/sites` is vacuous because that path is a bind mount with no mount unit. After a reboot they serve empty or root-disk data. Fix: `30-gate-services.sh` for all three, `systemctl disable` them.
3. **HIGH, CONFIRMED. A restore loses everyone's 2FA and push.** `scryproof-backup:43` archives `db.sql` and `uploads/` only. `.env` (SESSION_SECRET, VAPID keys) and `livekit.yaml` are not in it, and `infra/.env.example:27` says a new SESSION_SECRET makes stored TOTP seeds unreadable. Fix: add both files to the tar (it is already encrypted to the PC-only key).
4. **HIGH, PLAUSIBLE. "PC dies" has no inventory.** `release.sh:38` runs an uncommitted `~/ship.sh` in WSL; private files on this PC: `~/.ssh/scryproof` (no second copy recorded), `~/.scryproof/update-key.pem` and `~/.scryproof-backup/` (Bitwarden copies logged), the LUKS header backup (never logged as copied off the box). Fix: commit `ship.sh`, write `docs/box/if-the-pc-dies.md` listing each private file and its verified second copy.
5. **HIGH, CONFIRMED. Signing out or changing the password does not close live sockets.** `services/auth.ts:542-554` only writes `revokedAt`; no route calls the hub. The header comment at `gateway/index.ts:4-6` claims otherwise. A stolen signed-in laptop keeps receiving every message and presence event after the password change. Fix: on revoke, close `hub.connectionsForUser(userId)` sockets with 4001.
6. **HIGH, CONFIRMED. No error boundary, and one bad gateway frame poisons the queue forever.** `main.tsx:37-42` renders bare; `store.tsx:1680-1691` chains `queue.then(...)` with no catch, so after one throw every later event is skipped while the socket looks open. This is the blank-screen incident from 2026-10-06. Fix: one class boundary around App with "something broke, reload", and `.catch(() => undefined)` on the queue.
7. **HIGH, CONFIRMED. Pass-along store has no real ceiling.** `store.mjs:39` slices the list to 50, then `:68` compares that to `MAX_LOOPS` 200, so POST never returns 429. 24 layers x 1.6 MB clips means a stranger with curl can write thousands of loops of up to 38 MB each; `list()` parses every file on every request, `MemoryMax=128M` OOMs, the unit restart-loops. Fix: count files on disk, cap a loop's file size, keep clips out of `list()`.
8. **HIGH, CONFIRMED. Lost saves when two people work at once.** `store.mjs:76-92` reads the loop, awaits the body, then writes the whole loop back. A presence POST (every 20 s from every open tab) landing in that gap silently drops the other person's layer. Fix: await the body first, then read-mutate-write with no await between.

## Next (abuse, robustness, operations)

9. **HIGH, CONFIRMED. Nothing runs before a deploy.** `release.sh` checks a clean tree and a dated changelog entry, then signs and ships. No typecheck, no tests, no CI. Fix: `npm run typecheck && npm test` above the sign step (about a minute).
10. **HIGH, CONFIRMED. SSH is root on port 22, PermitRootLogin yes** (live facts). Key-only auth holds it, fail2ban status is not checked by `00-facts.sh`. Fix: `PermitRootLogin prohibit-password`, add the fail2ban line to facts.
11. **MEDIUM, CONFIRMED. No monitoring of any kind.** No uptime check, no disk warning (vault 10 GB, 4.3 GB free, holds swap, releases, 100 MB uploads and 7 backups), backups pulled by hand, `scryproof-backup.service` has no `OnFailure`. Fix: `OnFailure` flag surfaced by `/api/health`, weekly `backup-pull.sh` plus `backup-check.mjs` on a schedule.
12. **MEDIUM, CONFIRMED. Channel uploads have no rate limit or quota.** `routes/attachments.ts:59-126`: 100 MB per file, no `consume()`, unclaimed files live 24 h. DM files are limited, channel files and avatars are not. One account can fill the volume. Fix: per-user limiter and unclaimed-bytes ceiling.
13. **MEDIUM, CONFIRMED. Gateway has no per-socket rate limit** for `typing`/`presence` (`gateway/index.ts:297-331`); each typing frame does four queries and a permission fan-out. Fix: one `consume()` at the top of `handleClientEvent`.
14. **MEDIUM, CONFIRMED. Login limiter keyed on untrimmed username** (`routes/auth.ts:102` vs `services/auth.ts:676` trims), so padding gives fresh buckets. Fix: trim before keying.
15. **MEDIUM, CONFIRMED. Activities iframe gets the mic silently in the app.** `permissions-core.js:119-126` auto-grants audio to the activities origin, which is served by the box. A compromised box serving a modified page gets live mic audio outside E2EE with no prompt. Fix: a visible one-time consent per session, and never label it encrypted.
16. **MEDIUM, CONFIRMED. HTML injection via loop and player names.** `store.mjs:28` keeps `<>&"`; the page uses innerHTML (`passalong.js:324,530-532`). Scripts are blocked by CSP but `style-src 'unsafe-inline'` lets a 30-char loop name blank the list for everyone. Fix: escape on render.
17. **MEDIUM, CONFIRMED. Every viewer refetches the whole loop, vocals included, every 15 s** (`passalong.js:497`). Three vocals layers is about 5 MB per 15 s per phone. Fix: ETag or a tiny meta endpoint.
18. **MEDIUM, CONFIRMED. Mic stays open if you Leave while "waiting"** (`passalong.js:289-303`): the stream and 80 ms meter only close in `onstop`, which needs tick 0. Fix: release in Leave and Drop.
19. **MEDIUM, CONFIRMED. Dropped layers leave synth and rack nodes running.** `unplumb` (`passalong.js:198`) never calls `inst.destroy()`/`rack.destroy()` and the per-layer limiter stays on master. Likely part of the "gets taxing over time" report. Fix: destroy them in `unplumb`.
20. **MEDIUM, PLAUSIBLE. Slow recovery after sleep or a blip.** `gateway.ts:103-112` backs off to 30 s and nothing listens for `online`/`visibilitychange`; heartbeat has no pong deadline. Fix: reset backoff and reconnect on those events.
21. **MEDIUM, CONFIRMED. Session expiry has no message**, and API 401s are not handled (`api.ts:108-133`): a stale tab shows "Request failed (401)" per click. Fix: a one-line reason on the sign-in screen, treat 401 like close 4001.
22. **MEDIUM, CONFIRMED. One 1.7 MB chunk.** Emoji data, three canvas scenes, eight games and livekit all eager. Fix: `React.lazy` the games and scenes, dynamic import emoji data, `manualChunks` for livekit.
23. **MEDIUM, CONFIRMED. Every presence or typing event re-renders every message row** (single store context, no `memo` in MessageList/MessageRow/MemberList). Felt on phones in big calls. Fix: `memo(MessageRow)` or split presence/typing/voice into their own contexts.
24. **MEDIUM, CONFIRMED. Mac DMG fallback is unverified** against the signed manifest (`shell-update-mac.js:299,317`). Fix: sign the DMG hash in the manifest and check it in-app.
25. **MEDIUM, CONFIRMED. Mac entitlements wider than needed** (`entitlements.mac.plist:6-11`: `disable-library-validation`, `allow-unsigned-executable-memory`). Fix: drop both, rebuild on Trey's Mac, check mic/camera/PTT.
26. **MEDIUM, CONFIRMED. One signing key, no rotation path** (`signing-key.mjs:160-177`). Losing it means every install is reinstalled by hand. Fix: a second offline recovery keypair baked into the next installer.
27. **MEDIUM, PLAUSIBLE. Restore plus DNS move has never been rehearsed**; `backup-check.mjs` loads SQL into PGlite, which is not a restore. Fix: one timed rehearsal on a throwaway droplet.
28. **MEDIUM, CONFIRMED. Outbound 443 is open to anywhere** (`40-firewall.sh:49`); the "no phone-home" claim is unproven for HTTPS. Fix: log outbound 443 for a day and match every destination.
29. **MEDIUM, CONFIRMED. Untested security paths:** server `totp`, `channel-keys`, `audit`, `livekit`, `serialize`; web `permissionMeta`, `gateway`, `push`, `usePermissions`; desktop `main.js` glue (protocol path check, `/api/` forwarding, navigation guards, CSP). Fix: one test each, hostile-input style like the existing `dm-hostile` tests.

## What is notably good

- Boot-dumb is real: tmpfs flag asserts, masked `ssl-cert.service`, unlock refuses to bind over a non-empty dir, swap off before lock.
- No key that decrypts member content exists on the server, checked route by route; wrapped keys only, voice keys client-made and relayed opaque, push pings empty.
- Login timing equalized with a dummy argon2 verify; argon2id at OWASP params; 256-bit session tokens stored hashed; IPs hashed with a per-boot salt in logs.
- Hidden channels answer 404 everywhere including gateway fan-out; attachments served under `default-src 'none'; sandbox` with SVG excluded.
- Update verification is layered and tested as "what a server could try": Ed25519 with separate context strings, monotonic versions, re-verified at apply time; Mac adds codesign strict against a pinned Developer ID.
- Electron hardening is textbook: contextIsolation, sandbox, fuses off, window-open denied, webview blocked.
- Client E2EE: non-extractable keys, TOFU never auto-pins, the UI says "encrypted" only when `isE2EEEnabled` is true and says NOT encrypted otherwise.
- Supply chain: install scripts off, exact pins, 7-day cooldown, LiveKit and Node checksum-pinned, 0 audit findings.
- Twelve real-browser proof scripts and hostile-reviewer tests that attack the threat model, not just the happy path.
- Activities: tight CSP, triple-checked postMessage, atomic publish with `node --check` and `mv -T`, systemd unit with a dedicated user and an empty capability set.
